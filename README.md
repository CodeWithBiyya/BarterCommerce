# 🛒 BarterCommerce

BarterCommerce is an Android application that enables users to exchange products without using money. It provides a secure platform where users can upload products, browse listings, and chat with each other for item exchanges.

## ✨ Features

- User Authentication
- Product Listings
- Product Search
- User Profiles
- Product Details
- Real-time Chat
- Image Upload
- Firebase Storage
- Admin Approval
- Responsive Material UI

## 🛠️ Tech Stack

- Kotlin
- Firebase Authentication
- Firebase Firestore
- Firebase Realtime Database
- Firebase Storage
- RecyclerView
- Glide
- MVVM
- XML
